Slow-Fast Gradient Effect: Gradual transitions within categories, sharp at boundaries

1. Traditional vs Slow-Fast Gradient

Traditional: Simple two-color gradient with smooth transition across the entire bar.

Traditional Gradient

Slow-Fast: Multiple phases with gradual color changes within each phase (slow), but sharp visual boundaries between phases (fast) created by borders.

Slow-Fast Gradient 
/* Each phase has gradual transitions within (10%, 50%, 90% stops) */
background: linear-gradient(90deg,
    #4a9eff 0%,
    #4a9eff 10%,    ← Slow start
    #5ca9ff 50%,    ← Smooth mid
    #6bb5ff 90%,    ← Slow end
    #6bb5ff 100%
);

/* Sharp boundary via CSS border */
border-right: 2px solid rgba(10, 10, 10, 0.5);

4. Key Design Concepts

✓ Slow Gradient (Within Category):

  • Uses multiple color stops (0%, 10%, 50%, 90%, 100%)
  • Colors transition gradually across the phase width
  • Creates smooth, visually appealing gradient effect

✓ Fast Gradient (At Category Borders):

  • Sharp 2px borders between phase segments
  • Creates clear visual separation between categories
  • Uses semi-transparent borders for subtle but effective contrast

✓ Progressive Opacity:

  • Submission: 100% opacity (fully visible)
  • Review: 90% opacity (e6 suffix)
  • Appeals: 70% opacity (b3 suffix)
  • Completion: 50% opacity (80 suffix)
